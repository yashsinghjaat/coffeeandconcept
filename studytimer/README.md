# Coffee & Concepts Study Timer 🎓☕

A beautiful, standalone web-based study timer with café aesthetics. Perfect for focused sessions with Pomodoro, streaks, media backgrounds, music, weather, and more.

## ✨ Features
- **Central Countdown Timer** (HH:MM:SS input, progress circle)
- **Pomodoro Presets** (25m/50m/15m buttons)
- **Auto-break switching** (5min after focus ends)
- **Study Streaks** (localStorage tracked)
- **Multi-tool Sidebar**: Stopwatch, break timer, backgrounds (img/video), music, color picker, secure weather
- **Themes** (dark/light toggle)
- **Fullscreen mode**
- **Responsive** mobile-friendly
- **Glassmorphism UI** with animations

## 🚀 Quick Start
1. Open `index.html` in any browser
2. Set time (e.g. `25:00`) or use preset → Start focus
3. Customize with tools (hamburger menu)
4. Get WeatherAPI.com key for weather feature

**No setup required!** Pure HTML/CSS/JS.

## 📱 Demo
Run this in terminal: `start studtimer/index.html` (Windows)
